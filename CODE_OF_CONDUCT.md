# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming, respectful,
and harassment-free experience for everyone, regardless of background, identity,
experience, or skill level.

## Expected Behavior

Participants are expected to:

- Be respectful, constructive, and considerate.
- Welcome different perspectives and experiences.
- Give and accept feedback professionally.
- Focus on what is best for the project and its community.
- Respect the project's rules, maintainers, and other contributors.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, trolling, unwanted
sexual attention, publishing private information, and any other conduct that
would reasonably make someone feel unsafe or unwelcome are not acceptable.

## Reporting

If you experience or witness unacceptable behavior, please report it privately
to the project maintainers through GitHub at
<https://github.com/suwupnil/hacktoberfest>. Please avoid posting sensitive
details publicly.

All reports will be reviewed promptly and kept confidential where possible.

## Enforcement

Project maintainers may remove comments or contributions, close discussions,
restrict participation, or take other action they consider appropriate in
response to violations of this Code of Conduct.

This Code of Conduct applies within project spaces and whenever someone is
representing the project or its community.
